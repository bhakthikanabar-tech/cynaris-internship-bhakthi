# Cynaris Solutions – Data Analyst Internship

## Project: EDA on Indian Business Dataset

This repository documents my learning, practical assignments, SQL queries, Python implementations, and project progress during my 12-week Data Analyst Internship at Cynaris Solutions.

The project focuses on developing practical data analytics skills through hands-on exercises and real-world business dataset analysis.

## Technologies & Tools

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- SQLite
- Jupyter Notebook
- Git & GitHub
- VS Code

## Dataset

**Dataset:** Sample Superstore Dataset

- Records: 9,994
- Columns: 21
- Contains information about orders, customers, products, sales, profits, and regions.

## Internship Progress

### Week 1 – Data Foundations & SQL

**Day 1 – Exploratory Data Analysis**

- Started the Indian Business Dataset project.
- Explored the Sample Superstore dataset.
- Examined the dataset structure and business-related information.

**Day 2 – SQL Fundamentals**

- Practised SQL data retrieval and filtering.
- Worked with SQL queries using SQLite.

**Day 3 – SQL Aggregations**

- Practised COUNT, SUM, AVG, MIN, and MAX.
- Worked with GROUP BY and HAVING.
- Explored business KPIs using SQL.

**Day 4 – SQL Subqueries and CTEs**

- Practised nested and correlated subqueries.
- Learned non-correlated subqueries.
- Worked with CTEs and recursive CTEs.
- Practised EXISTS and IN.

**Day 5 – Python for Data: Pandas Basics**

- Loaded CSV files into Pandas DataFrames.
- Explored data using head(), info(), describe(), and value_counts().
- Practised filtering rows and selecting columns.
- Identified and handled missing values.
- Performed grouping and aggregation using groupby().
- Exported cleaned data to CSV.
